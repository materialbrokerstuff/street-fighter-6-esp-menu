## 🧩 About

**Street Fighter 6 Overlay** is a curated list of Street Fighter 6 open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, frame data display
- **Quality-of-Life Helpers** — move list catalog, skin manager, overlay notes
- **Research Notes** — training layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Frame Data Overlay — view frame advantages and disadvantages during training
- Hitbox Viewer — visualize attack and hurtbox hitboxes
- Input Display — on-screen input history for combo practice
- Playback Speed — adjust training playback for study (0.1x to 5x)

### Wallhack
- Costume Catalog — browse costumes, colors, and titles
- Custom Skin Notes — organize player cosmetics
- Stage Viewer — preview stages and lighting

### Aimbot
- Training Mode Notes — segment study on any character
- Dummy Control — manually set dummy behavior mid-training
- Combo Buffer Notes — chain complex maneuvers in training
